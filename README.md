---

## 🚀 Features

- 📄 **WHOIS Lookup** – Domain registrar, creation & expiry dates, name servers
- 🌐 **DNS Records Scanner** – A, AAAA, MX, NS, TXT, CNAME, SOA
- 🔎 **Host Info** – IP addresses (IPv4 & IPv6), reverse DNS
- 🎨 **CLI Banner** – Eye-catching ASCII art banner using `pyfiglet`
- 💡 **Beginner Friendly** – Great for Python learners and infosec students

---

## 🛠️ Installation

### Prerequisites

- Python 3.8 or higher

### Setup

```bash
# Clone the repository
git clone https://github.com/3jibon/whoLook_me.git
cd whoLook_me

# Install dependencies
pip install -r requirements.txt

# Run the tool
python whoLook_me.py
